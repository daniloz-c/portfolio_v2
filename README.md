# Projeto Danilo César

Site de portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades e projetos na área de Tecnologia da Informação.

## Sobre o projeto

- Apresenta minha stack de desenvolvimento e infraestrutura.
- Reúne projetos, artigos publicados e podcast.
- Inclui forma de contato e acesso ao currículo.

## Estrutura

- `src/` - arquivos principais da página
- `img/` - imagens usadas no site
- `docs/` - artigos e currículo em PDF
- `podcasts/` - arquivo de áudio do podcast

## Tecnologias

- HTML
- CSS
- JavaScript
- Tailwind CSS
